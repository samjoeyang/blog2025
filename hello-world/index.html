✅ 9. 常见命令速查表

命令 说明
hexo init 初始化博客
hexo new "title" 新建文章
hexo g 或 hexo generate 生成静态文件
hexo s 或 hexo server 本地预览
hexo d 或 hexo deploy 部署到远程
hexo clean 清除缓存和旧文件

✅ 10. 推荐插件（可选）

  • 搜索功能：hexo-generator-search
  • RSS 支持：hexo-generator-feed
  • 站点地图：hexo-generator-sitemap
  • 自动草稿管理：hexo-auto-categorize
