Array()
FUNCTION: 返回一个数组
SYNTAX: Array(list)
ARGUMENTS: 字符，数字均可
EXAMPLE: <%
Dim myArray()
For i = 1 to 7
Redim Preserve myArray(i)
myArray(i) = WeekdayName(i)
Next
%[/IMG]
RESULT: 建立了一个包含7个元素的数组myArray
myArray("Sunday","Monday", ... ... "Saturday")
