四种风险应对策略：规避、转移、减轻、接受

2026-07-15 项目管理 🎧 朗读

PMP职场实战108问 · 第35问

风险来了，你是逃、甩、扛、还是躺？

上周跟一位项目经理吃饭，他说自己最近快被风险搞疯了。项目上线前一天，客户突然要求换数据库——从MySQL换成Oracle。理由是“集团总部统一标准”。他当时脑子嗡的一声：工期、成本、团队技能、数据迁移……全崩了。

他问我：“遇到这种事，除了硬扛，还有什么办法？”

我说：“你先搞清楚，风险有四种死法，你选哪一种。”

他愣住了。

大多数项目经理面对风险时，只有两个反应：焦虑或者焦虑到放弃思考。 但PMBOK教我们的四种策略——规避、转移、减轻、接受——本质上是帮你从“情绪应激”切换到“策略选择”。

我们一个一个说。

策略一：规避（Avoid）——从根上掐灭

核心逻辑： 改变计划，让风险根本不会发生。

这不是逃避。规避是主动动作，比如换一个更成熟的方案、砍掉高风险功能、或者延长工期到风险自然消失。

真实案例：
我在做某银行核心系统升级时，发现第三方API接口有严重的安全漏洞。距离上线只有两周，修复需要至少一个月。我的决定：临时切换成自研模块替代，虽然功能少一点，但规避了数据泄露这个“灭顶之灾”。安全团队投了赞成票，客户虽然不满意功能缩水，但听到“漏洞”两个字也闭嘴了。

什么时候用：

  • 风险影响大到不可接受（比如安全事故、法律违规）
  • 有低成本替代方案
  • 你还有调整计划的余地

一句话口诀： 惹不起，躲得起。躲要躲得漂亮，不是放弃。

策略二：转移（Transfer）——把锅甩给能扛的人

核心逻辑： 把风险后果和应对责任转给第三方。

注意，转移不是甩锅不管。转移需要支付成本（保费、保证金、外包溢价），换来的是你那边的确定性。

典型操作：

  • 给关键设备买保险（出了事保险公司赔）
  • 把高风险部分外包给专业公司（他们更懂怎么处理）
  • 合同中设置明确的违约责任和赔偿条款

真实案例：
我之前做一个海外数据中心迁移项目，团队没人做过跨境合规。我直接把合规审查外包给了一家律所。签合同的时候，我写了一句：“如因合规问题导致项目延期，乙方需承担每日X元的违约金。”他们收了双倍费用，但我不在乎。因为我知道，一旦出问题，客户罚我的金额是外包费的10倍。

⚠️ 误区： 很多人以为转移就是“把活扔给外包就不管了”。错。你依然要监控——如果外包公司自己搞砸了，风险还是会回到你头上。

策略三：减轻（Mitigate）——降低概率或影响

核心逻辑： 我们接受这个风险存在，但想办法让它伤害更小。

这是项目经理最常用的策略。因为它不需要大动干戈，只需要4个字：提前准备。

具体做法：

  • 增加测试轮次 → 降低上线后故障概率
  • 准备备用方案 → 万一主方案失效，切换时间从2天降到2小时
  • 增加人手或资源 → 用冗余抗住不确定性
  • 设置缓冲期 → 最坏情况发生时，你还剩2周保底

真实案例：
我做一个电商大促项目，预估流量是平时的20倍。我知道服务器肯定扛不住，但老板不给加预算买新机器。怎么办？减轻。我做了三件事：

  1. 提前做压测，找到瓶颈点
  2. 准备降级方案——如果系统顶不住，先关闭非核心功能（比如推荐算法），保证下单和支付
  3. 周末安排值班团队，随时手动干预

结果当天流量确实超了，但只崩了10分钟，因为降级策略直接切了。你没能力完全消除风险，但可以把它从“致命伤”变成“擦破皮”。

策略四：接受（Accept）——躺平，但要有底牌

核心逻辑： 承认风险存在，不主动处理，但准备好钱和时间来应对。

很多人不理解：为什么不做任何事？因为有的风险，处理它的成本比风险本身还高。

常见类型：

  • 主动接受： 你知道下雨概率30%，但带伞的成本更高，所以你不带，淋了再说
  • 被动接受： 你根本没发现风险，它发生了你才面对（这是最差的）

真实案例：
我做内部工具开发时，明知某供应商可能延期交付（过去3次延期了2次），但我没换供应商，也没催他加急。为什么？因为那个工具是内部用，即使晚两周上线，对公司业务影响微乎其微。我预留了两周缓冲期，如果真延期，我拿缓冲期填上就行。

接受的前提是：这个风险发生后果你能兜住。别拿底线风险去赌。

一张表说清楚四种策略

策略 本质 典型方法 成本 适合场景
规避 改变计划让风险消失 换方案、砍功能 高（可能影响范围） 风险影响不可接受
转移 让别人承担后果 保险、外包、合同条款 中（保险费、溢价） 自己扛不住，别人能
减轻 降低概率/影响 加测试、加备选、加缓冲 低到中 大多数日常风险
接受 不主动处理，留后路 预留时间/资金 最低 影响小，或处理成本太高

给一个可复用的决策框架

下次你遇到风险，别先慌，拿这张清单过一遍：

第一步：问自己——这个风险我能不能完全躲开？
→ 能 → 规避
→ 不能 → 看第二步

第二步：问自己——别人有没有可能帮我扛？
→ 能，且价格合理 → 转移
→ 不能 → 看第三步

第三步：问自己——我能不能让它伤害小一点？
→ 能，且成本小于收益 → 减轻
→ 不能 → 看第四步

第四步：认命，但准备好钱和时间 → 接受

这个流程我用了7年，从没失手。
