<p><a href="http://wowubuntu.com/librecad.html">LibreCAD</a> 是一款开源免费的 2D CAD 制图软件，原名为 CADuntu 。它是基于社区版本 QCad 构建，并利用 Qt4 进行了重构，原生支持 Mac OSX, Windows 和 Linux 。它提供了基于 GPL 协议的读取/修改/创建 CAD 文件 (.dxf ) 方案。<br />＃截图：<br /><img src="/images/needisme/2010/12/101221_CADuntu-unnamed-document-1_03.png" width="600" /><br />项目主页： <a href="http://www.librecad.org/">http://www.librecad.org/</a></p>
<p>＃ 安装：<br />Ubuntu 10.04:<br />
<blockquote>sudo add-apt-repository ppa:showard314/librecad<br />sudo apt-get update<br />sudo apt-get install librecad</p></blockquote>
<p>Ubuntu 10.10 和 11.04:<br />
<blockquote>sudo add-apt-repository ppa:showard314/ppa<br />sudo apt-get update<br />sudo apt-get install librecad</p></blockquote>
