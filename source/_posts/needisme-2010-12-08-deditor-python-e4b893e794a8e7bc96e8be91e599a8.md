<p><a href="http://wowubuntu.com/deditor.html">Deditor</a> 是一款专用于 Python 语言的轻量级编辑器，使用 Python 及 wxPython 开发。它主要功能有支持语法高亮、代码折叠、同时打开多文件、自动缩进等等。另外，最新的 0.2.3 版还提供了插件功能，插件的开发文档看<a href="http://kruptein.alwaysdata.net/docs/">这里</a>。<br />
截图：</p>
<p><img src="http://wowubuntu.com/wp-content/uploads/2010/12/101208_Selection_05.png" alt="" /></p>
<p>项目主页： <a href="https://launchpad.net/deditor/">https://launchpad.net/deditor/</a></p>
<p># 安装：</p>
<p>Deb 包下载： <a href="http://www.omgubuntu.co.uk/2010/12/python-editor-deditor-0-2-3-new-features">https://launchpad.net/deditor/+download</a></p>
<p>安装信赖包：</p>
<blockquote><p>apt-get install wxgtk2.8</p></blockquote>
